# DANHAYS | The Home of Melanin Beauty

🌍 **A multi-brand curated marketplace celebrating Black & Brown beauty**

---

## 📋 Project Overview

DANHAYS is a comprehensive e-commerce platform dedicated to serving melanin-rich skin with the world's best curated beauty products. We celebrate inclusive beauty by featuring 50+ brands across 190+ countries.

### ✨ Key Features

- **🎨 2,500+ Products** across 8 main categories
- **👥 50+ Partner Brands** (Black-owned, African, Inclusive)
- **🌍 51 Languages** (38 African + 13 European)
- **💱 11 Currencies** for global commerce
- **💳 174+ Payment Methods** (including M-Pesa, Paystack, Flutterwave)
- **🤖 AI Tools** (Shade Finder, Virtual Try-On, Skin Analysis)
- **❤️ Community Hub** with 500K+ members
- **📱 Social Commerce** (TikTok, Instagram integration)
- **🏪 Omnichannel** (Online + 25 store partners)
- **🎁 Loyalty Program** (Melanin Rewards)

## 🚀 Quick Start

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- No installation needed! Start exploring immediately.

### Local Development

```bash
# Clone the repository
git clone https://github.com/faarahmd-dotcom/danhays.git
cd danhays

# Open in browser
# Simply open public/index.html in your web browser
# Or use a local server:

# Python 3
python -m http.server 8000

# Node.js (with http-server)
npm install -g http-server
http-server

# Then visit: http://localhost:8000
